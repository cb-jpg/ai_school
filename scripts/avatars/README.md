# 小石、小萌模型修复（2026-10-18）

本目录保存修复后的 PNG 图层、模型生成器补丁、动作生成脚本和运行时回归检查。
运行模型位于 `live2d-models/xiaoshi`、`live2d-models/xiaomeng`。

## 直接查看和测试表情

在项目根目录运行 `node scripts/avatars/serve-check.mjs`，打开终端输出的**人物预览**链接。
预览页为 `scripts/avatars/preview.html`，可以切换小石/小萌、选择 8 种表情、拖动或用滑杆转头、
文字朗读、口型演示，以及上传本机音频测试音量驱动的嘴巴开合。
文字朗读取决于本机浏览器是否提供语音；“口型演示”无需语音服务，上传音频在浏览器本地处理。

如果服务运行在远程服务器，请在 VS Code 的“端口”面板转发 3020，再在本机浏览器打开链接。
原来的 `runtime-check.html` 是只显示 PASS / 错误信息的自动检查页。
已经启动 3020 服务时，可以直接将浏览器地址末尾的 `runtime-check.html` 改为 `preview.html`。

## 原画表情素材

素材来自用户提供的 `石门实验学校IP设计（终稿）-JPG.rar`：第 18 页小石、第 22 页小萌。
两页原稿保存在 `expression-sources/`，提取的透明图层及定位坐标在 `expression-art/`。
新增喜、怒、哀、乐、惊恐、无语、害羞、哭共 8 种表情；沿用原稿眉眼、怒气、红晕和泪水，
嘴部保留独立动画，因此不是直接替换一张静态脸图。强表情期间保留原稿眼型，默认“喜”继续自动眨眼。

`art_expressions.py` 将图层绑定到原有头部和共同的身体/呼吸变形，表情文件显式清除其他表情，
避免连续切换后残留上一张脸。`smirk` 保留为“乐”的兼容别名。
`model_dict.json` 增加 bored / shy / cry 标签，并将 disgust 映射到“无语”；标准语音和浏览器备用语音
都应用服务器返回的表情。效果截图和本次检查结果在 `docs/avatar-expressions-20261018/`。

## 修改内容

- 网格覆盖检查包含每个网格单元内的全部透明度像素，避免漏掉脸颊、下巴的细轮廓。
- 导出时为所有部件保留共同的呼吸和身体运动参数；先排除已由头部变形器承担的参数，
  再执行参数数量限制，避免脸和外轮廓在呼吸时错开。
- 头部转向采用抛物线深度，并限制转头、抬头、侧倾的幅度，减少大眼睛附近的挤压和颈部脱离。
- 增加藏在脸和衣服后面的颈部图层；头发与脸交界处增加底层覆盖。
- 头部旋转中心改到下巴与颈部的连接点，转头投影扣除连接点的位移，避免侧倾时露出断口。
  清理两个角色下巴轮廓中残留的衣领裁切尖角。哭、哀、怒使用可辨认的下弯嘴形，哭的静止口型闭合，
  播报时仍由音量驱动开合。
- 后脑贴图同时包含脸颊和下巴轮廓，因此关闭该图层的独立发丝摆动，保留整头、身体和呼吸运动。
- 去掉小萌衣服图层中两块重复的发梢，避免转头后碎片停留在肩膀旁。
- 每个角色有 3 段待机和 4 段说话动作，包含点头、侧倾、身体轻摆、眨眼和眉毛变化。
- 禁用生成器误加在校服上衣、短裤上的独立裙摆/衣料变形及其物理驱动，保留身体轻摆和呼吸。
  浏览器左右拖动会同时驱动头部与身体；错误的裙摆物理曾把袖口与手臂、裤腿与小腿拉开。
- 说话动作不写入 `ParamMouthOpenY`，由语音播放控制嘴巴；表情不会覆盖播报期间的开合。
- 正常音频通过 PCM 音量驱动口型；浏览器备用语音没有 PCM 接口，使用模拟开合。
- 长句会接续说话动作；结束、失败或打断时回到待机。取消后的音频加载结果不能恢复口型。

默认动作没有启用大幅挥臂。原画手臂与衣服分层的连接处不足以支持自然的大幅摆动；
后续如需招手，需要先补全被遮住的肩膀和手臂图层。生成器的独立调试动作仍保留。


写回源目录。审阅输出后，用每个角色的完整输出目录替换对应运行目录，不能只替换 moc3。
