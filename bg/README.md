# 背景图片目录

## 使用说明

将学校背景图片放到这个目录中，支持以下格式：
- JPG (.jpg, .jpeg)
- PNG (.png)

## 推荐的图片尺寸和规格

- **尺寸**: 1920x1080 或更高
- **比例**: 16:9 (横向)
- **大小**: 建议 < 2MB 以获得更好的加载性能

## 添加背景图片后的操作

1. 将图片文件复制到此目录
2. 在右侧侧栏的"背景图片"选项中应该会自动显示
3. 点击对应的背景选项即可切换
