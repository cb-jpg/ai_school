# 浏览器 ASR 人工测试

## 记录环境

浏览器及版本：待填写；操作系统：待填写；麦克风：待填写；是否耳机：待填写。

## 步骤

1. 通过 SSH 隧道打开 `http://localhost:12393`。
2. 检查页面显示的安全上下文、`mediaDevices` 和 Web Speech 支持情况。
3. ASR 选择器依次选择“自动选择”“浏览器语音识别”“服务器本地识别”。
4. 每次只点击“开始说话”，说完后等待最终文本，再观察 `本轮 ASR` 和临时文本。
5. 在自动模式下禁用 Web Speech 或制造网络错误，确认出现“已切换到本地识别”，且同一 `utterance_id` 只提交一次。
6. 测试播放回答约 20 秒时点击打断，再输入新问题，确认旧音频约 1 秒内停止且没有重叠。
7. 不说话播放回答，记录是否产生自我识别；调整音量后重复。

## 隐私提示

Web Speech 的识别实现由浏览器和操作系统决定，部分浏览器可能向厂商云端发送音频，不能视为完全离线。要求音频不出设备时应强制选择“服务器本地识别”。
