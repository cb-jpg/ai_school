# 微信公众号接入说明（2026-09-20 需求 #7）

> 结论先行：**能接**。公众号图文有两条接入路线——A 官方接口自动同步（需要学校提供公众号
> 授权，约 1~2 天开发）；B 管理后台手动贴链接（**现在就已可用**，零开发）。
> 视频号官方没有开放内容接口，只能人工方式入库（见文末）。
> 内容入库后，数字人即可在回答中引用（走既有 RAG 检索）；时效类问题另有联网检索兜底。

---

## 一、现状：公众号内容怎么进入数字人的知识

数字人的回答来自服务器上的「学校知识库」（RAG 检索）。任何内容只要入库为知识条目，
下一次提问即可被检索到，**不需要重启或重新打包**。入库渠道现有三个：

1. 管理后台（#/main → 知识库管理）上传文件（txt/docx/pdf）；
2. 管理后台「添加链接」：贴一个网页地址，服务器自动抓取正文入库——
   **公众号推文链接（mp.weixin.qq.com/…）理论上可直接贴**，正文抽取失败时降级用路线 3；
3. 批量灌库脚本（`scripts/knowledge_data/seed_via_api.py`，已有 220 条在库）。

## 二、路线 B（推荐先做）：运营老师每周贴链接，零开发

**做法**：学校公众号运营老师每周（或每次重要推文发布后）登录管理后台，
把推文链接贴进「知识库管理 → 添加链接」，分类选「学校介绍」、打上 `微信公众号` `新闻` 标签。

- 优点：当天可用、无需任何授权、内容经老师筛选（天然过审）。
- 缺点：靠人工，容易忘。
- 注意：贴**文章原文链接**（`https://mp.weixin.qq.com/s/…` 或 `/s?__biz=…` 形式），
  不要贴搜狗微信搜索的中转链接（那种链接有签名，会过期且常被微信风控拦截）。
- 建议给运营老师定一个最小节奏：**每周五贴一次本周推文**，3~5 分钟的事。

## 三、路线 A（正式方案）：官方接口自动同步

公众号后台开放了「发布内容」接口，授权后服务器可以**每天自动**拉取最新推文入库。

### 1. 学校需要做的（约 10 分钟，需公众号管理员）

1. 公众号管理员扫码登录 [mp.weixin.qq.com](https://mp.weixin.qq.com)；
2. 左侧「设置与开发 → 基本配置」→ 同意成为开发者；
3. 页面上有 **AppID（开发者ID）** 和 **AppSecret（开发者密码）**，点「重置」生成 AppSecret
   并复制（只显示一次）；
4. 同页面「IP 白名单」→ 填入学校服务器 IP：**183.36.243.124**（不改白名单接口会报
   40164 invalid ip 错误）；
5. 把 AppID 和 AppSecret 通过**安全渠道**（当面/电话，不发群不发邮件明文）交给项目开发。

### 2. 我们侧的实现（拿到 AppID/Secret 后 1~2 天）

- 服务器新增定时任务（每日 1 次）：
  1. 用 AppID+Secret 换 `access_token`（有效期 7200 秒，本地缓存复用）；
  2. 调「获取成功发布列表」`POST /cgi-bin/freepublish/batchget` 分页拉取已发布图文；
  3. 对每篇新文章调 `/cgi-bin/freepublish/getarticle` 取正文，清洗 HTML 后
     经既有知识库 API 建条目（标签 `微信公众号`，正文里的图片不取）；
  4. 按标题幂等，重复文章自动跳过。
- 接口配额充足（素材类接口每日各 10 万次量级），一天一次同步可忽略不计。

### 3. 安全约定

- **AppSecret 只存服务器**（`data/` 下的本地配置，不进 git、不打进前端包）；
- AppSecret 泄露 = 别人可冒用公众号身份调接口，一旦怀疑泄露就在后台「重置」；
- IP 白名单保证即使 Secret 泄露，外部 IP 也换不到 token；
- 同步入库的是**已发布**图文，学校编辑部审核流程不变。

### 4. 接口权限前提

`freepublish`（发布能力）与素材接口要求公众号**已完成微信认证**。
学校公众号为机构主体、一般都已认证；若未认证，后台会直接看不到对应权限，
届时退回路线 B（或先做微信认证，300 元/年审核费，学校行政决定）。

## 四、视频号：没有开放接口，只能人工

微信**没有**对视频号内容提供第三方读取接口（搜一搜/视频号助手均不对外开放）。
可行做法：

- **文字稿入库**（推荐）：视频号发布的活动视频，把解说词/要点整理成一段文字
  （或直接把公众号对应图文贴链接），入库后数字人就能讲；
- 对话中用户问起视频号，数字人回答「视频号名称/去微信搜索 XXX 观看」——
  把视频号名称作为一条知识条目录入即可；
- 不建议用第三方爬虫服务（wewe-rss 等逆向方案），稳定性差且有封号风险。

## 五、落地节奏建议

| 阶段 | 内容 | 前置条件 | 工作量 |
|---|---|---|---|
| 一期（现在） | 路线 B：老师每周贴推文链接入库 | 无 | 0 |
| 二期 | 路线 A：官方接口每日自动同步 | 学校提供 AppID/Secret + IP 白名单 | 1~2 天开发 |
| 三期 | 官网「新闻公告」栏与知识库同源展示（需求 #5 的一部分） | 二期数据管道 | 1 天 |
