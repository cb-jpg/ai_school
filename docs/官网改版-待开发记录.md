## 技术要点（后续维护者）

- **路由**：`App.tsx` `getCurrentRoute`——空 hash/`#/home` → hero 首页；
  `#/campus/<column>/<article>`（+旧链映射）与 `#/news` → hero 覆盖页
  （`activeColumn`/`isNewsActive` 状态，页头由 App 级渲染 z40，须压过页面根 z30
  否则下拉面板被页面盖住）；
  `#/hero` 对话（登录门禁）；`#/main` 管理后台。main 模式（Electron）的
  pushState 专题导航不受影响。
- **主题与页头**：颜色/字体唯一定义在 `site-theme.ts`；页头 `site-header.tsx`
  （红横带 + TopicTabRow 白导航条，`items` 传入栏目下拉结构；TopicTabRow 的
  kiosk JS 拖滑兜底未动）。栏目/新闻页 top 避让 base 112 / lg 128 / 竖屏大屏 164px，
  改页头高度要同步。**09-22 起设置面板/登录页/对话页/字幕条也统一走 site-theme
  （各文件内用语义别名 `schoolColors` 指向主题 token），新增界面禁止再散落色值**；
  管理后台 #/main（admin/sidebar/portal/knowledge 组件）仍是旧配色，如需换装按同法。
- **图层**：首页 banner 背景层 zIndex base 1 / md 0（压画布 base15/md1 下），
  红面板等内容 z20，页头 z40 —— 人物因此"站"在 banner 照片上、内容之下。
  栏目/新闻页根 z30 盖过画布：卡片区域会挡人物，人物只能落在页面留白区
  （栏目/新闻页内容行固定 58% 宽，右 42% 留白就是人物位），改布局别把卡片铺进右区。
- **人物站位**：`use-live2d-model.ts` 常量组：对话 HERO_* / 手机首页 HOME_*
  （=BANNER 组）/ 竖屏大屏 HOME_BOARD_* / 桌面栏目新闻 COLUMN_DESKTOP_*
  （base×0.66、view(0,-0.28)、x=0）；适配 effect 各页必跑（就绪判据
  `canvas.width >= clientWidth×dpr - 1`），对话页目标=恢复加载默认
  （pristine scale 按 baseModelRef 实例身份捕获，模型重载自动重取）。
  屏幕比例→view-x 换算 `(2f-1)×宽高比` 只对全宽画布成立（右 55% 画布直接用 view 坐标）。
  匿名模型来自 `/live2d-models/info`（websocket-handler 回退），登录后由 WS
  `set-model-and-conf` 覆盖。
- **站位验证**：`D:\SRP\AI_school\cdp_position_check.py`——公网四页
  （首页→hash 切栏目→新闻→student01 登录对话）帧缓冲 alpha 包围盒 + DOM 矩形
  逐页断言（banner/内容行不相交、页头 zIndex），canvas 帧合成回 DOM 截图供目检；
  toDataURL 与渲染循环有竞态（preserveDrawingBuffer=false），须重试抓非空帧。
- **冒烟脚本**：本地 `cdp_site_preview.py`（9 检查：首页手机/桌面、栏目页切文、
  旧链映射、招生数据、新闻中心、下拉交互、匿名登录门禁）；公网
  `cdp_public_site_check.py`（HTTP /media 匿名 + 首页人物站位帧缓冲包围盒 +
  栏目讲解登录浮层 + student01 对话）。**注意公网脚本每轮清 Edge profile，
  否则上一轮登录态会让匿名检查失真**。
- 数据边界：新闻/公告为静态占位（角注已标），正式化走待开发第 1 条。
