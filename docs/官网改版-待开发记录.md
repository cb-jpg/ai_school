## 技术要点（后续维护者）

- 路由：`frontend/src/renderer/src/App.tsx` 的 `getCurrentRoute`——
  空 hash/`#/home`/`#/portal`(兼容)/`#/landing`/`#/campus/*` → hero；
  `#/hero` 对话（登录门禁）；`#/main` 管理后台。
- **主题与页头**：颜色/字体唯一定义在 `components/hero/site-theme.ts`；
  页头 = `components/hero/site-header.tsx`（红横带 + TopicTabRow 白导航条，
  激活态由 `activeNav` 决定），home-page / hero-landing 直接渲染；
  专题页（campus-knowledge）hero 模式不渲染页头（由 hero-landing 统一出），
  仅 main 模式（Electron 工作台）保留旧内部导航卡。旧 `navbar.tsx`/
  `mobile-menu.tsx` 已删除。
- **hero 专题页避让**：campus-knowledge 根容器 top 按页头高度写死
  （base 112px / lg 128px / 竖屏大屏 164px）——改 SiteHeader 高度时三处要同步。
- 人物：Live2D 画布是 App 级穿透层（zIndex 15），内容层 z20（页头 z30）；
  站位由 `use-live2d-model.ts` 的 HOME_*/HOME_BOARD_* 常量控制，与本次改版无关。
- 若将来恢复长页门户：`portal-content.ts` 数据仍在（新闻/公告已被首页消费）；
  注意 App 锁 body 滚动，长页需自带 overflowY 容器。
