# 双 ASR 对比

当前服务器没有浏览器会话、麦克风或 SenseVoice 模型，以下结果均为 `PENDING`，不是通过声明。

| 项目 | Web Speech | SenseVoice |
|---|---|---|
| 浏览器支持 | 待 Chrome/Edge 实测 | 不依赖浏览器 Web Speech |
| 是否依赖外网 | 可能依赖浏览器服务 | 模型下载后可离线 |
| 是否可能上传音频 | 是，取决于浏览器实现 | 否，音频发往本服务器 |
| 识别准确率 | 待测 | 待测 |
| 首次启动时间 | 待测 | 待测，首次可能下载模型 |
| 平均识别耗时 | 待测 | 待测 |
| 校园专有名词 | 待测 | 待测 |
| 离线能力 | 不保证 | 模型就绪后支持 |
| 一体机迁移风险 | 浏览器/网络差异 | 模型、CPU/GPU 和驱动差异 |
| 推荐使用场景 | 默认低延迟交互 | Web Speech 不可用或隐私强约束 |

建议架构结论：`A. Web Speech 作为默认，SenseVoice 作为回退`，但最终一体机上线前仍需重新验证浏览器和隐私要求；若要求音频完全不出设备，应切换为 `C. 只使用 SenseVoice`。
